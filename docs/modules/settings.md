# Workspace Settings Module

Route: /settings
Title: Workspace Settings

## Current Build Snapshot

- Company Workspace card: company identity used by web and synced to Android.
- Invite User: company accounts + 5-minute invite codes (screen/SMS/WhatsApp/Email).
- Company Accounts and Recent Invites tables.
- Licence Expiry Reminders status with link to the Notification Centre.
- **Users & Access — Company Users** (OWNER/ADMIN only): list, create (server-issued `CMU-…` ID + one-time passcode via callable), edit (name/role/permissions), reset passcode (shown once), suspend/reactivate, optional link to an existing pilot record. Creating a user never creates a Pilot record.

## Next Enhancements
- Organization profile and contact settings.
- Notification preferences and reminder defaults.
- Dedicated Admin module extraction once a second management surface appears.
