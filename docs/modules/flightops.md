# Flight Ops Module

Route: /flightops
Title: Flight Ops

## Current Build Snapshot
- **Operations Team**: owners/admins can add named operations staff under `companies/{companyId}/people` with role `OPERATIONS`. These source records appear in Linking & Access; credentials are generated there. The module includes a shortcut to the team form.
- Team source records are separate from Company Home login accounts. Each person can be linked to one account.
